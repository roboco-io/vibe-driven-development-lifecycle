# 릴리즈 노트

VDLC는 완성된 문서가 아니라 계속 진화하는 방법론이다. 버전은 SemVer를 따른다: 전제·핵심 명제가 바뀌면 major, 원칙·구조가 추가되면 minor, 표현·오탈자 수정은 patch. 방법론이 진화해 온 궤적 자체가 VDLC가 말하는 "환류"와 "학습 자산"의 실례다.

## v1.3 — 2026-07-25

**주간 사이클 — 쿨다운 포함 한 주가 한 심박**

- 기본 사이클을 6일 빌드 + 2일 쿨다운(약 1.5주)에서 **4일 빌드 + 1일 쿨다운(한 주)**로 재설계 — 월요일 아침 베팅, 목요일 검증 게이트, 금요일 쿨다운으로 달력 주에 정렬
- 명칭을 "6일 사이클"에서 "주간 사이클"로 변경
- 변형 재정렬 — 상향 8일 + 2일(2주, 엔터프라이즈), 하향 2일 + 1일(사흘) 유지

## v1.2 — 2026-07-25

**사이클 길이 재정의 — 재베팅 리듬과 하향 변형**

- 사이클을 작업 시간의 추정치가 아니라 재베팅 리듬으로 재정의 — 적정 길이는 검증 자산 성숙도·정보 도착 속도·이해 대역폭의 함수
- 하향 변형(2일 빌드 + 1일 쿨다운) 신설 — 검증 자산이 성숙한 자산화(Compounding) 이상 팀과 솔로·소규모 팀 대상
- 캘리브레이션 절차를 변형 단위 이동 규칙(연장·단축 조건)으로 구체화

## v1.1 — 2026-07-25

**6일 사이클과 프로토타입 주도 shaping**

- Basecamp Shape Up의 6주 사이클을 VDLC 전제 위에서 재해석한 [6일 사이클](/ko/cycle) 페이지 신설 — 6일 빌드 + 2일 쿨다운, 컨텍스트 브레이커, 병렬 베팅, 위임 가능성 지도, 검증 게이트
- 프로토타입 주도 shaping 도입 — 수렴형(고속 반복)·발산형(병렬 큐레이션) 두 패턴, throwaway 원칙, 결정기록(Decision Record) 자동 생성
- 핏치 템플릿 정의 — 이중 통화 Appetite, Rabbit Holes, No-Gos, 결정기록 링크
- 릴리즈 노트 페이지와 사이트·슬라이드 버전 표시 도입
