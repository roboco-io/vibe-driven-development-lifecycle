# 릴리즈 노트

VDLC는 완성된 문서가 아니라 계속 진화하는 방법론이다. 버전은 SemVer를 따른다: 전제·핵심 명제가 바뀌면 major, 원칙·구조가 추가되면 minor, 표현·오탈자 수정은 patch. 방법론이 진화해 온 궤적 자체가 VDLC가 말하는 "환류"와 "학습 자산"의 실례다.

## v1.2 — 2026-07-25

**라이프사이클 상세 다이어그램 — 주체와 하네스의 순환 뷰**

- 매니페스토·랜딩의 P1~P6 단순 다이어그램을 순환 링 다이어그램으로 교체 — 단계별 인간/AI 작업, 주도권, 인간 관문(계획 승인·최종 리뷰·배포 승인), 자동 가드레일을 한 화면에 담는다
- Vue 컴포넌트 1벌 + 로케일 문자열 데이터 구조로 구현, 3개 로케일(영문·한국어·일본어) 지원
- 좁은 화면(<960px)에서 1→6 세로 카드 스택으로 리플로우해 모바일 가독성 확보

## v1.1 — 2026-07-25

**주간 사이클과 프로토타입 주도 shaping**

- Basecamp Shape Up의 6주 사이클을 VDLC 전제 위에서 재해석한 [주간 사이클](/ko/cycle) 페이지 신설 — 4일 빌드(월~목) + 1일 쿨다운(금)으로 한 주가 한 심박. 컨텍스트 브레이커, 병렬 베팅, 위임 가능성 지도, 검증 게이트
- 프로토타입 주도 shaping 도입 — 수렴형(고속 반복)·발산형(병렬 큐레이션) 두 패턴, throwaway 원칙, 결정기록(Decision Record) 자동 생성
- 핏치 템플릿 정의 — 이중 통화 Appetite, Rabbit Holes, No-Gos, 결정기록 링크
- 사이클 길이를 재베팅 리듬으로 규정 — 적정 길이는 검증 자산 성숙도·정보 도착 속도·이해 대역폭의 함수. 변형: 상향 8일 + 2일(2주, 엔터프라이즈), 하향 2일 + 1일(사흘)
- 릴리즈 노트 페이지와 사이트·슬라이드 버전 표시 도입
